One thing in state 2 and 6 is not true today

Typing gold currently returns 36 results that all score exactly 68. Every hit ties, so the order is just array position — which is why four decorative “Vedanta demerger — gold globe” renders sit above IFM-101, IFM-099 and IFM-100. The tagging is correct; those renders carry no Gold topic. The ranking simply has no way to prefer an asset that genuinely is about gold.

Reaching the ordering shown above needs one scoring change: a query word that exactly matches a controlled Topic or Format should count for more than the same word appearing in a title or description. That is a few lines in the scorer, and it is what makes the “N relevant results” cutoff meaningful too — without a spread of scores there is no tail to cut.

You froze the search engine and asked me to stop and report rather than modify it, so I have not touched it. This is the one change I need approved before implementing. Everything else in this storyboard is presentation only.
